# Camera Pose Teleop Setup

This directory contains the reproducible installation and validation system for Camera Pose Teleop.

The setup system is organized around reusable components collected by machine-specific profiles.

Planned profiles:

- PC: perception, development, SONIC and MuJoCo simulation
- Jetson: onboard runtime and native deployment requirements
- Robot: Unitree, DDS and network integration requirements

The implementation will be derived from the audited known-good V2 system.

Generated environments, downloaded models, caches, logs, build products and machine-specific runtime state are not committed.
